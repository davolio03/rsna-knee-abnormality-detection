# Archived experiment records (E001–E049)

These records cover how the project got to its current model:

- Codex/SIWC report-labeling pilots (E001–E020);
- the 500-study cohort and DICOM reader (E021–E023);
- Kaggle training and audit iterations, and the ResNet-18/50 baselines (E024–E046);
- the first RadImageNet and attention submissions (E047–E049).

They are kept unedited as evidence. Some relative links pointed to documents that have since moved
or been removed. Check out the git tag `competition-archive-2026-11` to read them in their
original context.
