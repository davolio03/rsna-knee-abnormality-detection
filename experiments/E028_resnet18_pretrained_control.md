## Frozen protocol proposal

| Component | Both arms |
|---|---|
| Cohort and split | Existing fold 0; 333 training and 167 validation studies; preserve the existing grouped-fold artifact and its hash. |
| Sampling | Same study order, selected series/slices, and masks in both arms; no augmentation. |
| Input | Existing normalized grayscale `[0, 1]` 256×256 slices; repeat the grayscale channel three times, then apply the ImageNet V1 channel normalization (`mean=[0.485, 0.456, 0.406]`, `std=[0.229, 0.224, 0.225]`) at valid pixels. Keep invalid pixels zero after normalization and preserve the validity mask. |
| Resolution deviation | Do not use the bundled V1 256-resize/224-center-crop transform: the training protocol intentionally retains the established full 256×256 field and its mask. Use identical full-resolution preprocessing in both arms; record this as a deliberate deviation from the published inference recipe. |
| Backbone and pooling | ResNet-18 through the final spatial feature map, followed by the same validity-mask-aware spatial, slice, series, and study mean-pooling in both arms. Use one 12-logit linear head on the resulting 512-channel study feature in both arms. |
| Trainability | All ResNet-18 weights and the 12-output head are trainable in both arms. Keep BatchNorm modules in evaluation mode in both arms so running statistics are frozen; keep affine parameters trainable. Reapply BatchNorm evaluation mode after each model-wide train transition. |
| Memory | Process all series/slices: slice microbatches of two with non-reentrant activation checkpointing during training; no image/slice truncation beyond the existing dataset protocol. |
| Optimization | Same verified run04 config: fold 0, seed 42, BCE-with-logits, Adam at 0.001, five epochs / 1,665 study steps, no augmentation, final-checkpoint evaluation. The 333/167 split and manifest/fold hashes are unchanged. |
| Reporting | Same validation studies and single final evaluation pass for each arm; report macro AUC and all 12 per-target AUCs with undefined one-class targets explicit. Also report trainable-parameter counts and aggregate runtime. Never use validation results to alter either arm. |

The only allowed arm difference is initialization: random initialization (`weights=None`) versus the explicit `ResNet18_Weights.IMAGENET1K_V1` state. Do not use the moving `DEFAULT` alias.
